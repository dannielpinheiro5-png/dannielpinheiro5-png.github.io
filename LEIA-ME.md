# Portfólio — Daniel Pinheiro Negócios Digitais

O portfólio são 5 arquivos soltos, sem pastas: `index.html`, `estilo.css`, `portfolio.js`, `projetos.js` e este `LEIA-ME.md`.
Os mini apps não ficam aqui dentro: cada um continua no seu próprio repositório, publicado no GitHub Pages, e o portfólio exibe cada app dentro de um celular.

- Leonardo Soares Flores → repositório `leonardo-soares` → `/leonardo-soares/`
- Velas Botânicas → repositório `velas-botanicas` → `/velas-botanicas/`

Quando você atualiza um app no repositório dele, o portfólio já mostra a versão nova.

## Como publicar

1. Crie um repositório público chamado **dannielpinheiro5-png.github.io** (o link fica `https://dannielpinheiro5-png.github.io`).
2. **Add file → Upload files**, arraste os 5 arquivos e clique em **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch**, branch `main`, pasta `/ (root)` → **Save**.
4. Em 1 a 3 minutos está no ar.

## Como adicionar um projeto novo

1. Publique o app num repositório próprio, com o GitHub Pages ligado (como os dois atuais).
2. Abra `projetos.js` no GitHub e clique no lápis ✏️.
3. Copie um bloco inteiro `{ ... },`, cole no fim da lista e troque os textos.
   Em `app`, coloque o nome do repositório entre barras, por exemplo `"/meu-novo-app/"`.
4. Clique em **Commit changes**. O celular novo, a ficha e o contador aparecem sozinhos.
